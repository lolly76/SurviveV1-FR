Démarrage rapide

Installation en une commande (recommandée)
curl -fsSL https://raw.githubusercontent.com/lolly76/SurviveV1-FR/main/install/bootstrap.sh | bash

Vérifie le système, clone le dépôt, lance l'assistant (stockage, nom d'hôte, région des cartes, modèle d'IA), puis installe et démarre les services.

Installation manuelle
# 1. Cloner le dépôt
git clone https://github.com/lolly76/SurviveV1-FR.git ~/SurviveV1
cd ~/SurviveV1

# 2. Assistant interactif (ou : sudo bash setup/install.sh)
sudo bash install/wizard.sh

# 3. Télécharger les contenus (peut durer des jours)
bash download/download_all.sh --storage /mnt/survive

# 4. Démarrer les services
bash scripts/start_services.sh

# 5. Ouvrir http://localhost:8080  (ou http://survive.local:8080)
Télécharger une catégorie seulement
bash download/kiwix_content.sh          # Wikipédia FR et ZIM français
bash download/videos.sh                  # vidéos de survie
bash download/books_pdfs.sh              # PDF et livres
bash download/maps.sh --region france    # cartes de France
bash download/kolibri_content.sh         # Khan Academy FR
bash download/drug_reference.sh          # référence des médicaments (BDPM)

AI Hat et assistant IA

Le Hailo-8L (13 TOPS) est un accélérateur de vision : il ne peut pas accélérer les LLM d'Ollama. Avec un 8L, l'inférence se fait sur le processeur. Le Hailo-10H peut exécuter des LLM sur son NPU (pilotes différents : sudo bash scripts/setup_hailo10.sh) ; Ollama reste toutefois sur le CPU.

Mémoire du PiTaille de modèle conseillée
4 Gojusqu'à ~3 milliards de paramètres
8 Gojusqu'à ~7 milliards de paramètres

L'assistant cherche d'abord dans vos contenus hors ligne (Kiwix, documents, notices de médicaments) puis répond en français. La traduction de la partie IA (prompt, scripts) est prévue dans un second temps. Voir docs/ai_hat_setup.md.

2
Sans réseau (sans routeur) Point d'accès Wi-Fi

Le Pi diffuse son propre réseau Wi-Fi ; connectez un téléphone ou un ordinateur et ouvrez http://10.42.0.1:8080.

sudo bash scripts/hotspot.sh enable     # activer
sudo bash scripts/hotspot.sh disable    # désactiver (un redémarrage suffit aussi)
3
Aperçu de cette page sur votre ordinateur Sans installation

Ouvrez simplement index.html dans un navigateur, ou servez le dossier sur votre réseau local :

cd /chemin/vers/SurviveV1
python3 -m http.server 8000     # puis http://localhost:8000
