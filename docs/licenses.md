# SurviveV1-FR — Licences des contenus

Tous les contenus téléchargés restent soumis à leur licence d'origine. SurviveV1-FR ne redistribue
aucun contenu protégé : il fournit des scripts qui téléchargent des ressources diffusées librement par
leurs sources. Les licences ci-dessous sont indicatives ; **vérifiez les conditions exactes sur le site
de chaque source** avant toute redistribution.
