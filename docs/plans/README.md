# Plans de conception (historique)

Ces fichiers (`completed/PLAN-*.md`) sont les notes de conception des fonctionnalités du
projet d'origine (schwadb/SurviveV1), traduites en français. Ils documentent le *pourquoi* du
code (RAG, flux du chat, recherche fédérée, point d'accès Wi-Fi, etc.), pas son utilisation.
Les noms de fonctions, fichiers et routes restent ceux du code ; certaines phrases d'exemple
qui apparaissent dans les prompts et les tests sont données en français, comme dans ce fork.
