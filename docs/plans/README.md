# Plans de conception (historique)

Ces fichiers (`completed/PLAN-*.md`) sont les notes de conception des
fonctionnalités du projet d'origine (schwadb/SurviveV1), rédigées en anglais
pendant leur développement. Elles documentent le *pourquoi* du code (RAG,
streaming du chat, recherche fédérée, point d'accès Wi-Fi, etc.) mais ne
décrivent pas l'utilisation : elles sont conservées **telles quelles, en
anglais**, pour garder la traçabilité avec le projet amont et faciliter la
synchronisation des correctifs. Les textes visibles par l'utilisateur
(interface, scripts, documentation d'usage) sont, eux, en français.
